# 20901-압둘라(Portfolio)

## 1. NT-SecurityChallenges 프로젝트 개발 시작
NiceTop 팀은 덕영고등학교 재학생을 대상으로 기초적인 해킹 기법을 교육하기 위해 **NT-SecurityChallenges** 프로젝트를 시작하였다.  
교육용 CTF 플랫폼을 목표로 웹 사이트 디자인 및 문제 문서화 작업을 중심으로 개발하였다.

---

## 2. NT-SecurityChallenges – 미르스타디움 CTF 개최
- **일시**: 2025년 5월 23일  
- **내용**: 덕영고등학교 미르스타디움 행사에서 NT-SecurityChallenges를 출품하여 CTF 대회 운영  
- **의의**: 실제 사용자 환경에서 플랫폼을 운영한 첫 사례
